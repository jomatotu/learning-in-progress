# 12. Glossar

| Begriff | Definition |
| --- | --- |
| Generative UI | Oberfläche, die das System zur Laufzeit für eine konkrete lernende Person und ein konkretes Material erzeugt. |
| Lernmaterial | Von der lernenden Person eingebrachter Inhalt, zum Beispiel Text oder Vorlesung. |
| Persona | Konkretes Nutzungsprofil, mit dem der Lösungsraum für den Hackathon eingegrenzt wird. |
| Profil | Beschreibung der lernenden Person: Herausforderungen, Ziele und das, was bereits funktioniert. |
